# Bouquet Builder

A browser-based game where users can create and arrange a flower bouquet, then save past creations.

## Features

- Click flower types to add them to the bouquet canvas.
- Drag flowers to arrange your bouquet.
- Select a flower to adjust size, rotation, and layer order.
- Duplicate and delete selected flowers.
- Save multiple bouquets to browser local storage.
- Load and delete previously saved bouquets.
- Draft autosave for in-progress work.

## Run

This project is static HTML/CSS/JS, so no install is needed.

From `/Users/subash/make-bouquet` run:

```bash
python3 -m http.server 8000
```

Then open:

- `http://localhost:8000`
